Charm Draft Bridge — Amaris Pilot

This browser extension carries one approved encounter packet from BHW Encounter Operations into the open CharmHealth draft without using the CharmHealth API.

Test with a synthetic training encounter first. The bridge fills detected draft fields but never saves, signs, prescribes, submits a claim, or releases information.
Download pilot extension Return to encounter queue
  1. Download and unzip the package.
  2. In Google Chrome, open chrome://extensions.
  3. Turn on Developer mode.
  4. Select Load unpacked and choose the unzipped bhw-charm-bridge folder.
  5. Pin the extension to the Chrome toolbar.
  6. Use a synthetic CharmHealth training encounter to test note and code-field detection.

The extension has no outside network connection and does not retain the note. Clinical content moves through the clipboard and the active CharmHealth page only.
